# futbolista-orders-assets

תמונות מוצר עם סימן מים של The Futbolista Closet, המשמשות כמקור תמונה חי לגיליון ההזמנות.

## למה זה ציבורי

הקבצים נצרכים כ-raw URLs ישירות מתוך נוסחאות `=IMAGE()` בגיליון הקטלוג.
**אסור להפוך את הריפו הזה לפרטי** - התמונות בגיליון יישברו מיידית.

## Structure
- קובץ PNG אחד לכל מוצר, בשם ה-handle של המוצר עם הסיומת `_wm`
